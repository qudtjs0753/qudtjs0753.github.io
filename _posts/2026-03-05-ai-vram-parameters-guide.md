"이 모델 내 GPU에서 돌릴 수 있을까?" — 로컬 LLM을 처음 시도할 때 누구나 하는 질문입니다. 답은 **파라미터 수 × 바이트 수 = 필요 VRAM**이라는 간단한 공식에서 시작합니다.

## 모델별 VRAM 참고표

실제로 가장 많이 궁금해하는 내용을 먼저 정리했습니다.

| 모델 크기 | INT4 추론 | FP16 추론 | 소비자 GPU 가능 여부 |
|-----------|-----------|-----------|---------------------|
| 7B        | ~4 GB     | ~14 GB    | INT4: RTX 3060도 가능 |
| 13B       | ~7 GB     | ~26 GB    | INT4: RTX 3080 가능 |
| 70B       | ~35 GB    | ~140 GB   | INT4: A100 80GB 1장 |
| 405B      | ~200 GB   | ~800 GB   | 멀티 GPU 서버 필요 |

> 위 수치는 **모델 가중치만** 올렸을 때의 최솟값입니다. 실제로는 KV 캐시, 컨텍스트 길이 등에 따라 추가 메모리가 필요합니다.
{: .prompt-info }

---

## 파라미터란?

파라미터는 모델이 학습을 통해 얻은 **숫자값(가중치)**입니다. GPT-3의 "175B"에서 B는 Billion(10억)을 뜻하며, 모델 안에 1,750억 개의 숫자가 저장되어 있다는 의미입니다.

이 숫자들이 곧 모델의 "지식"이고, 추론할 때 이 숫자들을 전부 GPU 메모리(VRAM)에 올려야 합니다. 그래서 파라미터 수가 곧 VRAM 요구량을 결정합니다.

---

## 데이터 타입별 파라미터 크기

파라미터 1개가 차지하는 메모리는 어떤 데이터 타입으로 저장하느냐에 따라 달라집니다.

| 데이터 타입 | 비트 | 파라미터 1개 크기 | 특징 |
|------------|------|------------------|------|
| FP32 (float32) | 32bit | 4 bytes | 훈련 기본값, 가장 정밀 |
| FP16 / BF16    | 16bit | 2 bytes | 추론에 주로 사용 |
| INT8           | 8bit  | 1 byte  | 양자화(quantization) |
| INT4 / NF4     | 4bit  | 0.5 bytes | 고압축, 약간의 정밀도 손실 |

FP32에서 INT4로 내려가면 파라미터 1개당 용량이 **8배** 줄어듭니다. 이것이 양자화가 로컬 LLM 실행에 핵심적인 이유입니다.

---

## VRAM 계산 공식

모델 로딩에 필요한 최소 VRAM은 다음과 같이 계산합니다.

```
필요 VRAM = 파라미터 수 × 파라미터 1개 크기(bytes)
```

7B 모델을 예시로 계산하면:

| 정밀도 | 계산 | 필요 VRAM |
|--------|------|----------|
| FP32   | 7B × 4 bytes | ~28 GB |
| FP16   | 7B × 2 bytes | ~14 GB |
| INT8   | 7B × 1 byte  | ~7 GB  |
| INT4   | 7B × 0.5 bytes | ~3.5 GB |

같은 7B 모델이라도 양자화 수준에 따라 28 GB부터 3.5 GB까지, **8배** 차이가 납니다.

---

## 추론 vs 훈련: VRAM 요구량 차이

**추론(Inference)**은 모델 가중치만 메모리에 올리면 됩니다. 하지만 **훈련(Training)**은 훨씬 더 많은 메모리가 필요합니다.

```
훈련 VRAM ≈ 모델 가중치 + 그래디언트 + 옵티마이저 상태 + 활성화값
           ≈ 파라미터 × ~16 bytes  (FP32 기준, Adam 옵티마이저 사용 시)
```

각 구성 요소를 풀어보면:

| 구성 요소 | 파라미터당 크기 | 역할 |
|-----------|---------------|------|
| 모델 가중치 | 4 bytes (FP32) | 현재 모델 상태 |
| 그래디언트 | 4 bytes | 손실 함수의 미분값 |
| 옵티마이저 (Adam) | 8 bytes | 1차/2차 모멘텀 |
| **합계** | **~16 bytes** | |

즉 7B 모델을 풀 파인튜닝하려면 약 **112 GB** VRAM이 필요합니다. RTX 4090 한 장(24 GB)으로는 불가능한 수준입니다.

> 이 때문에 LoRA, QLoRA 같은 **파라미터 효율적 미세조정(PEFT)** 기법이 등장했습니다. 전체가 아닌 일부 파라미터만 업데이트하여 VRAM 사용량을 대폭 줄입니다.
{: .prompt-tip }

## 핵심 정리

- **파라미터 수 × bytes = 기본 VRAM** — 이것이 모든 계산의 출발점입니다
- **양자화(INT4/INT8)로 최대 8배 VRAM 절약** — 로컬 실행의 핵심 기술입니다
- **훈련은 추론보다 ~4배 더 많은 VRAM 필요** — 가중치 외에 그래디언트, 옵티마이저 상태가 추가됩니다
- 그래서 로컬에서 LLM을 돌릴 때 **GGUF + llama.cpp** 같은 INT4 양자화 포맷을 사용합니다
